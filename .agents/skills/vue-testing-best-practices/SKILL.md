Vue.js testing best practices, patterns, and common gotchas.

### PULSO testing context
PULSO frontend tests currently run with Node’s test runner and repository HTTP helpers. Use the general black-box and async-testing guidance below, but inspect the project scripts before proposing Vitest, Vue Test Utils, or Playwright; do not install or assume those tools.
